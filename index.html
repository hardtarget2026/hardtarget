The problem

Nothing in Windows, SCCM, Intune, or any major MDM checks the actual physical security posture of a running machine. They check policy. Policy says one thing; the machine does another. Windows Update silently reverts your hardening. Nobody notices.

The Dolos Group pulled BitLocker keys from a locked corporate laptop with a $200 logic analyser. The laptop passed every compliance check in the org's tooling.

Every check maps to real attack scenarios: cold boot, DMA, evil maid, sleep/wake, forensic recovery, device compromise. The dashboard groups findings by threat so you see your actual exposure, not a flat list.

Modes

Audit - read-only dashboard. Changes nothing.

Expert - dashboard + fix engine. Beta. Every fix needs a confirmation code typed at the PowerShell console.

Report - JSON file only. No server, no dashboard.

Run it

# Double-click the BAT, or:
powershell -NoProfile -ExecutionPolicy Bypass -File .\HardTarget.ps1

# Read-only dashboard:
.\HardTarget.ps1 -ReadOnly

# JSON report only:
.\HardTarget.ps1 -Audit

Windows 10/11. PowerShell 5.1 (built in). Admin. Nothing else.

First run

Windows will try to stop you. Right-click the downloaded .ps1 file > Properties > check Unblock > OK. SmartScreen may warn on the BAT - click More info > Run anyway. If Defender quarantines the file, check Protection History and restore it.

Verify

# SHA256
Get-FileHash .\HardTarget.ps1 -Algorithm SHA256
